1) MaterialApp
Description: Root Material configuration for routes, theme, localization, and app-wide behavior.
Syntax: MaterialApp(title: 'App', theme: ThemeData(), home: HomePage())
Keyword Properties: title, theme, darkTheme, themeMode, home, routes, navigatorKey, debugShowCheckedModeBanner
Pseudo Code:
  create MaterialApp
  set theme and routes
  set home screen
Example:

    title: 'Shop App',
    theme: ThemeData(useMaterial3: true),
    home: const HomeScreen(),
  )

Keyword Properties: appBar, body, drawer, endDrawer, floatingActionButton, bottomNavigationBar, bottomSheet, backgroundColor
Pseudo Code:

Best Practices
- Start with MaterialApp + ThemeData for consistent styling.
- Prefer composable layout widgets (Row, Column, Expanded, Padding) over deeply nested Container.
- Use Material 3 controls (NavigationBar, FilledButton, NavigationDrawer) for modern UI.
- Keep UI state local where possible; move shared state to state management only when needed.
- Use Form + TextFormField for validation-driven input.
- Add semantic labels for accessibility and test key flows with widget tests.
